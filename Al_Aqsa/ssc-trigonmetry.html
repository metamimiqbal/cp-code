Introduction & Angle Measurement

What is Trigonometry?

Trigonometry (from Greek: trígōnon = triangle, métron = measure) is the branch of mathematics that studies relationships between angles and sides of triangles, extended to periodic functions on the unit circle.

Systems of Angle Measurement

Sexagesimal (Degree)

1 right angle = 90°
1° = 60 minutes (60')
1' = 60 seconds (60")
Full circle = 360°

Radian

Angle subtended by arc = radius
1 right angle = π/2 rad
Full circle = 2π rad
π rad = 180°

Centesimal (Grade)

1 right angle = 100 grades (g)
1g = 100 minutes
1 minute = 100 seconds
Full circle = 400g

Key Conversion: D/180 = R/π = G/200  →  where D = degrees, R = radians, G = grades
π rad = 180° → 1 rad = 180°/π ≈ 57.2958° → 1° = π/180 rad ≈ 0.01745 rad
Arc length: l = rθ (θ in radians)  |  Area of sector: A = ½r²θ

Fundamental Identities

Pythagorean Identities (Most Important)

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ → sec²θ − tan²θ = 1 → (secθ − tanθ)(secθ + tanθ) = 1
1 + cot²θ = cosec²θ → cosec²θ − cot²θ = 1 → (cosecθ − cotθ)(cosecθ + cotθ) = 1
Derived forms: sin²θ = 1 − cos²θ | cos²θ = 1 − sin²θ | tan²θ = sec²θ − 1 | cot²θ = cosec²θ − 1

Important Algebraic Identities for Proving

sinθ + cosθ = √(1 + 2sinθcosθ) = √(1 + sin2θ)
sinθ − cosθ = ±√(1 − sin2θ)
(sinθ + cosθ)² = 1 + 2sinθcosθ = 1 + sin2θ
(sinθ − cosθ)² = 1 − 2sinθcosθ = 1 − sin2θ
sin⁴θ + cos⁴θ = 1 − 2sin²θcos²θ = 1 − ½sin²2θ
sin⁶θ + cos⁶θ = 1 − 3sin²θcos²θ

Elimination & Proving Strategies

Strategy A: Convert everything to sin and cos, then simplify.
Strategy B: Work on more complex side. Multiply top & bottom by conjugate.
Strategy C: Use Pythagorean identity to replace sin²+cos²=1.
Strategy D: Factor using a²−b² = (a+b)(a−b), a³±b³ formulas.

Complementary & Supplementary Angles

Complementary Angles (A + B = 90°)

sin(90°−A) = cos A
cos(90°−A) = sin A
tan(90°−A) = cot A
cot(90°−A) = tan A
sec(90°−A) = cosec A
cosec(90°−A) = sec A
If A+B=90°: sinA = cosB, tanA = cotB, secA = cosecB (and vice versa). Use this to simplify sums like sin20°+sin70° = sin20°+cos20°.

Supplementary Angles (A + B = 180°)

sin(180°−A) = sin A
cos(180°−A) = −cos A
tan(180°−A) = −tan A
If A+B=180°: sinA = sinB, cosA = −cosB, tanA = −tanB.

Important Sum Results (SSC Level)

Classic Sums

sin²A + sin²(90°−A) = 1
tanA · tan(90°−A) = 1
secA · sec(90°−A) = cosecA · cosecA/...

Collinear Results

sin10°+sin20°+...+sin90° = sum
sin1°sin179°, cos1°cos179° etc.

Compound Angle Formulas

Addition & Subtraction Formulas

sin(A+B) = sinA cosB + cosA sinB
sin(A−B) = sinA cosB − cosA sinB
cos(A+B) = cosA cosB − sinA sinB
cos(A−B) = cosA cosB + sinA sinB
tan(A+B) = (tanA + tanB) / (1 − tanA tanB)
tan(A−B) = (tanA − tanB) / (1 + tanA tanB)
cot(A+B) = (cotA cotB − 1) / (cotA + cotB)
cot(A−B) = (cotA cotB + 1) / (cotB − cotA)

Key Derived Results

From sin(A+B)·sin(A−B)

sin(A+B)·sin(A−B) = sin²A − sin²B
= cos²B − cos²A

From cos(A+B)·cos(A−B)

cos(A+B)·cos(A−B) = cos²A − sin²B
= cos²B − sin²A

tan sum special

tan45°±tanA = (1 ± tanA)/(1 ∓ tanA)
If A+B+C=π: tanA+tanB+tanC = tanA·tanB·tanC
Common mistake: sin(A+B) ≠ sinA + sinB. Always expand using the compound formula.

Multiple & Sub-Multiple Angle Formulas

Double Angle (2A)

sin 2A = 2 sinA cosA = 2tanA/(1+tan²A)
cos 2A = cos²A − sin²A = 1 − 2sin²A = 2cos²A − 1 = (1−tan²A)/(1+tan²A)
tan 2A = 2tanA / (1 − tan²A)
sin²A = (1 − cos2A)/2 | cos²A = (1 + cos2A)/2

Triple Angle (3A)

sin 3A = 3sinA − 4sin³A
cos 3A = 4cos³A − 3cosA
tan 3A = (3tanA − tan³A) / (1 − 3tan²A)

Half Angle (A/2) — Sub-Multiple

sin(A/2) = ±√[(1−cosA)/2]
cos(A/2) = ±√[(1+cosA)/2]
tan(A/2) = ±√[(1−cosA)/(1+cosA)] = sinA/(1+cosA) = (1−cosA)/sinA
sin A = 2sin(A/2)cos(A/2) | cosA = 1 − 2sin²(A/2) = 2cos²(A/2) − 1

t-Substitution (t = tan A/2) — Higher Math

sinA = 2t/(1+t²)  |  cosA = (1−t²)/(1+t²)  |  tanA = 2t/(1−t²)   where t = tan(A/2)
Use: Solving equations of the form a·sinA + b·cosA = c by substituting t = tan(A/2).

n-Multiple Patterns (Higher Math)

sin nA in terms of sinA (Chebyshev-like expansion) — derived from de Moivre's (optional extension)
cos 4A = 8cos⁴A − 8cos²A + 1
sin 4A = 4sinA cosA(cos²A − sin²A) = 4sinA cos³A − 4sin³A cosA

Product-to-Sum & Sum-to-Product

Product → Sum (Higher Math)

2sinA cosB = sin(A+B) + sin(A−B)
2cosA sinB = sin(A+B) − sin(A−B)
2cosA cosB = cos(A−B) + cos(A+B)
2sinA sinB = cos(A−B) − cos(A+B)

Sum → Product

sinC + sinD = 2 sin[(C+D)/2] cos[(C−D)/2]
sinC − sinD = 2 cos[(C+D)/2] sin[(C−D)/2]
cosC + cosD = 2 cos[(C+D)/2] cos[(C−D)/2]
cosC − cosD = −2 sin[(C+D)/2] sin[(C−D)/2]
Tip: For sinC+sinD and sinC−sinD: first function matches middle of C and D (average), second function relates to their difference.

Important Conditional Identities (A+B+C = 180°)

sinA + sinB + sinC = 4cos(A/2)cos(B/2)cos(C/2)
cosA + cosB + cosC = 1 + 4sin(A/2)sin(B/2)sin(C/2)
sin2A + sin2B + sin2C = 4sinA sinB sinC
cos2A + cos2B + cos2C = −1 − 4cosA cosB cosC
tanA + tanB + tanC = tanA·tanB·tanC
tan(A/2)tan(B/2) + tan(B/2)tan(C/2) + tan(C/2)tan(A/2) = 1
Higher Math key: All conditional identities are derived using A+B = 180°−C, then applying compound/double angle formulas.

Standard Problem Types

Type 1: Single Observation

h = d · tan α (h=height, d=horizontal dist, α=elevation angle)

Type 2: Two Observations (Same Side)

h = d · tanα · tanβ / (tanβ − tanα) where d = distance between two points, α & β = elevation angles (β > α from farther point)

Type 3: Observations from Top & Bottom

If angle of depression from top = β, angle of elevation from foot = α:
h/H = tanα/tanβ (for equal horizontal distance)

Type 4: Object Between Two Observers

h = d · sinα · sinβ / sin(α+β) where d = distance between observers, α and β = elevation angles

Type 5: Shadow Problems

Shadow length s = h / tanα where α = angle of elevation of sun
SSC exam focus: Most problems are Type 1 or Type 2. Draw the diagram first, label all known and unknown quantities, then write the trig equation.

Solution of Triangles (Higher Math)

Sine Rule (Law of Sines)

a/sinA = b/sinB = c/sinC = 2R (where R = circumradius)
Use when: Given two angles + one side (AAS/ASA), or two sides + non-included angle (SSA, ambiguous case).

Cosine Rule (Law of Cosines)

a² = b² + c² − 2bc·cosA
b² = a² + c² − 2ac·cosB
c² = a² + b² − 2ab·cosC
cosA = (b² + c² − a²) / 2bc (finding angle from all three sides)
Use when: Given three sides (SSS), or two sides + included angle (SAS).

Projection Formulas

a = b·cosC + c·cosB
b = a·cosC + c·cosA
c = a·cosB + b·cosA

Napier's Analogies (Higher Math)

tan[(A−B)/2] = [(a−b)/(a+b)] · cot(C/2)
tan[(B−C)/2] = [(b−c)/(b+c)] · cot(A/2)
tan[(A−C)/2] = [(a−c)/(a+c)] · cot(B/2)

Area of Triangle

Δ = ½ · a · b · sinC = ½ · b · c · sinA = ½ · a · c · sinB
Δ = √[s(s−a)(s−b)(s−c)] (Heron's formula, s = (a+b+c)/2)
Δ = abc / 4R (using circumradius R)
Δ = r · s (using inradius r, semi-perimeter s)

Circumradius, Inradius & Exradii

R = abc / 4Δ (circumradius)
r = Δ/s = (s−a)tanA/2 = 4R·sin(A/2)sin(B/2)sin(C/2) (inradius)
r₁ = Δ/(s−a) | r₂ = Δ/(s−b) | r₃ = Δ/(s−c) (exradii)
r₁ = s·tan(A/2) | r₂ = s·tan(B/2) | r₃ = s·tan(C/2)
1/r = 1/r₁ + 1/r₂ + 1/r₃ | r·r₁·r₂·r₃ = Δ²

Half Angle Formulas for Triangles

sin(A/2) = √[(s−b)(s−c)/bc] | cos(A/2) = √[s(s−a)/bc] | tan(A/2) = √[(s−b)(s−c)/s(s−a)]
sin(B/2) = √[(s−a)(s−c)/ac] | cos(B/2) = √[s(s−b)/ac]
sin(C/2) = √[(s−a)(s−b)/ab] | cos(C/2) = √[s(s−c)/ab]

Key Theorems & Special Results

Maximum & Minimum Values

a·sinθ + b·cosθ: max = √(a²+b²), min = −√(a²+b²)
a·sin²θ + b·cos²θ: max = max(a,b), min = min(a,b)
sinθ ∈ [−1,1], cosθ ∈ [−1,1], for all θ
tan θ can take any real value; |sinθ| ≤ 1; |cosθ| ≤ 1

General Solutions of Trig Equations

sinθ = sinα → θ = nπ + (−1)ⁿα (n ∈ Z)
cosθ = cosα → θ = 2nπ ± α (n ∈ Z)
tanθ = tanα → θ = nπ + α (n ∈ Z)
Note: Principal solutions are specific values in [0, 2π). General solutions cover all solutions.

Important Special Angles (Higher Math)

sin 18° = cos 72° = (√5 − 1)/4 | cos 36° = sin 54° = (√5 + 1)/4
sin 36° = cos 54° = √(10 − 2√5)/4 | cos 18° = sin 72° = √(10 + 2√5)/4
sin 15° = cos 75° = (√6 − √2)/4 | cos 15° = sin 75° = (√6 + √2)/4
tan 15° = 2 − √3 | tan 75° = 2 + √3 | tan 22.5° = √2 − 1 | tan 67.5° = √2 + 1

Weierstrass Substitution Summary

Let t = tan(θ/2): sinθ = 2t/(1+t²), cosθ = (1−t²)/(1+t²), tanθ = 2t/(1−t²), dθ = 2dt/(1+t²)

Complex Number Link (Euler's Formula — Higher Extension)

e^(iθ) = cosθ + i·sinθ (Euler's formula)
cosθ = (e^(iθ) + e^(−iθ))/2 | sinθ = (e^(iθ) − e^(−iθ))/2i
Extension: de Moivre's theorem: (cosθ + i sinθ)ⁿ = cos(nθ) + i sin(nθ) — used to derive multiple angle formulas.
