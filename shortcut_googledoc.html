Power User Combos
FORMAT PAINTER
Select source text → ⌘+⌥+C → select target → ⌘+⌥+V
Clones all formatting in one move.
QUICK HEADING HIERARCHY
⌘+⌥+1 → H1  ·  ⌘+⌥+2 → H2  ·  ⌘+⌥+0 → Normal
Structure a whole doc without touching the toolbar.
JUMP TO ANY MENU
Press ⌥+/ to open a menu search. Type anything — insert table, page numbers, image — and hit Enter.
Fastest way to find buried features.
WORD-BY-WORD MOVEMENT
⌥+←/→ jumps word by word. Add ⇧ to select while jumping. Add ⌫ to delete the previous word instantly.
MOVE PARAGRAPHS FAST
Click inside any paragraph, then ^+⇧+↑/↓ to reorder it without cut-paste. Works with list items too.
VERSION HISTORY SHORTCUT
Press ⌘+⌥+⇧+H to jump straight to version history. Useful for recovering deleted content or reviewing edits.
COMPACT MODE
Press ^+⇧+F to hide all toolbars and get a distraction-free full-screen writing mode. Press again to exit.
